# apps

Public pages for the apps I build: landing pages, privacy policies, terms. Served by GitHub Pages
at https://shivasaxena.com/apps/. One folder per app; never delete a folder once an app is on a store,
because the store listing points at it.

| Path | What |
|---|---|
| `index.html` | The landing page listing projects |
| `style.css` | Shared styles |
| `ohmydare/` | Oh My Dare: landing page and privacy policy |
